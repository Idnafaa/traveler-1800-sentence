One sentence explaining the modern internet to a traveler from 1800, built only from pictures that traveler already knows — a road, a library, a post office, a market — so the idea can be held in their head with no word coined after their time: "It is a road joining every library, post office, and market on earth, so any letter, book, or spoken word can reach anyone in a single breath, and an answer can come back just as fast."

## Run it

```sh
python3 main.py
```

The sentence is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
